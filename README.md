# SISTEMA-DE-BIBLIOTECA---IA---PIAGET- TRABALHO DE ADS 3º E 4º SEMESTRE
Esse é um sistema simples desenvolvido com IA - QWen e Lovable - sistema bonito dinamico , mas que apresenta falhas e dificuldades no manuseio , que  pessoas especializadas e com conhecimento para realizar a manutenção.
A intençao desse projeto é mostrar que mesmo com a facilidade de criar software com IA , é essencial pessoas qualificadas para gerir os mesmos e atender os requisitos funcionais e não funcionais basicos
